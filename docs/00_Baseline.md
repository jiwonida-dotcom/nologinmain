## 운영 규칙

- ID 체계: 확정 `C-nn` · 미확정 `O-nn` · 개발 협의 `D-nn` · 페인포인트 `P-nn` · 개선 원칙 `G-nn` · 목표 지표 `M-nn` · 예외 `EX-nn`
- **근거 열은 비워두지 않는다** — `[관측]` `[데이터]` `[추론]` `[합의]` 중 하나
  - `[관측]` 실제 화면에서 직접 확인 → 재현 경로를 함께 적는다
  - `[데이터]` 분석 도구 수치 → 기간 · 표본 수 · 도구명
  - `[추론]` 위 둘에서 유도 → 유도 논리 한 줄
  - `[합의]` 이해관계자 결정 → 결정자 · 시점
- 확정 여부(C/O)와 근거 강도는 **별개 축**이다. `C-nn` + `[추론]` 조합은 따로 뽑아 검증한다
- `[추론]`이 Critical 페인포인트의 유일한 근거이면 수동 검증 후 승격하거나 등급을 낮춘다
- 항목 확정 시: Baseline 갱신 → 본문 반영 → 문서 버전 올림 → 카운터(확정 N / 미확정 N / 협의 N) 일치 확인
- 관측 사실이 정정되면 그 항목에 의존하는 서술(페인포인트 · 캡처 캡션 · 시나리오)을 전부 추적해 함께 고친다
