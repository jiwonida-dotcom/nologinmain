## 7. 세션 운영 규칙 · 함정

### 반드시 지킬 것
- **연결 폴더에서 `git` 명령 실행 금지.** `git status` 만으로도 `.git/index.lock` 이 남고, 삭제 권한이 없어 이후 `push.cmd` 가 「Another git process seems to be running」 으로 전량 실패. 상태 확인은 파일 단위로만
  - 이미 발생했다면 `.git/index.lock` 삭제 필요 (연결 폴더 삭제 권한 승인 또는 탐색기에서 수동 삭제)
- **`device_commit_files` 는 같은 `stagedPath` 재사용 시 이전 내용이 전송된 사례 있음.** 매번 고유 파일명 사용 후 크기 · 해시 검증
- 커밋 · push 는 사용자가 `push.cmd` 실행. 세션은 파일 수정까지만

### 작성 · 구현 규칙
- 변경은 **Baseline 먼저** → 문서 본문 → 리포트 → 버전 · 카운터 일치
- 근거 열 `[관측] [데이터] [추론] [합의]` 필수. 임의 의사결정 금지, 확정 전 사용자 확인
- 문장: 명사형 종결 · 간결 · 중복 금지
- 원문(Figma · 지시문)은 오타 포함 그대로 기재. 정정안은 별도 표기
- CSS 접두사: 리포트 `r-` · 프로토타입 `np-` · 프레임 `.phone` — 서로 손대지 않음
- 외부 CDN · localStorage 금지. 이미지 base64 임베딩. 폰트 `font/PretendardVariable.woff2` 상대경로
- 화면 전체를 덮는 요소(토스트 · 레이어 팝업)는 **`.phone` 직속** 배치 — `.ph-body` 안에 두면 스크롤과 함께 밀림
- JS 검증: `node -e "const s=require('fs').readFileSync('index.html','utf8');const i=s.lastIndexOf('<script>')+8,j=s.lastIndexOf('</script>');try{new Function(s.slice(i,j));console.log('JS OK')}catch(e){console.log('ERR',e.message)}"`
