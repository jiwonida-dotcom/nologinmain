## 7. 세션 운영 규칙 · 함정

### 반드시 지킬 것
- **연결 폴더에서 `git` 명령 실행 금지.** `.git/index.lock` 잔존 → `push.cmd` 전량 실패. 상태 확인은 파일 단위로만. 이미 발생했다면 `.git/index.lock` 수동 삭제
- **파일 수정은 `device_bash` 안에서 python 히어독으로 직접 적용** — 임시 스크립트를 폴더에 커밋하면 세션이 지우지 못해 사용자가 삭제해야 함(09-18 2회 발생)
- 적용 후 로컬 · 세션 사본 **md5 대조** + JS 검증. 세션 사본(cloud)은 Playwright 렌더 확인용
- 커밋 · push 는 사용자 `push.cmd`. 세션은 파일 수정까지만

### 작성 · 구현 규칙
- 변경은 Baseline 먼저 → 문서 본문 → 리포트 → 버전 · 카운터 일치
- 근거 열 `[관측] [데이터] [추론] [합의]` 필수. 임의 의사결정 금지, 확정 전 사용자 확인 — **디자인 방향은 `AskUserQuestion` 선택지로 먼저 확인** (범위 · 톤)
- 명사형 종결 · 간결 · 중복 금지. 원문(Figma · 지시문)은 오타 포함 그대로
- CSS 접두사: 리포트 `r-` · 프로토타입 `np-` · 프레임 `.phone` `.ph-*`. **스타일 고도화는 `np-polish` 블록에 덮어쓰기로만 추가**
- 레이아웃 수치 유지가 원칙일 때: 테두리는 `inset box-shadow` · 폰트 크기 변경은 `line-height` 고정 · 여백 조정은 해당 블록 `margin` 으로(공통 gap 불변)
- 외부 CDN · localStorage 금지. 이미지 base64 · 아이콘은 인라인 SVG 우선(PNG 마젠타 잔존 재발)
- 화면 전체를 덮는 요소(토스트 · 레이어 팝업)는 `.phone` 직속
- JS 검증: `node -e "const s=require('fs').readFileSync('index.html','utf8');const i=s.lastIndexOf('<script>')+8,j=s.lastIndexOf('</script>');try{new Function(s.slice(i,j));console.log('JS OK')}catch(e){console.log('ERR',e.message)}"`
