# 분석 프레임워크

각 섹션의 목적은 "무엇이 일어났는가(데이터) → 왜 일어났는가(원인) → 무엇을 바꿀 것인가(개선안)"를 잇는 것이다. 데이터가 없는 칸을 억지로 채우지 말고 "추정" 표시 후 근거 수집 방법을 제안한다.

## 1. Dashboard 분석

Sessions, Users, Time on Page, Bounce, Exit, Returning Users를 조회하고 다음을 해석한다:

- 트래픽 대비 이탈: Bounce/Exit가 높은 페이지는 어디인가
- Returning Users 비율: 재방문이 낮으면 첫 경험 문제, 높은데 전환이 없으면 결정 장애 신호
- 디바이스별 차이: 모바일 vs 데스크톱 지표 차이가 크면 반응형 문제 의심
- 유입 채널별 차이가 있으면 채널-랜딩 불일치 검토

## 2. Heatmap 분석 (스크린샷 제공 시)

Click / Scroll / Attention 각각에 대해:

① 가장 많이 클릭되는 요소 — 의도된 CTA인가?
② 예상 외 클릭 — 클릭 안 되는 요소를 클릭(Dead Click 후보), 이미지·텍스트 클릭은 "더 알고 싶다"는 신호
③ 클릭되지 않는 CTA — 위치, 시인성, 문구 문제 구분
④ 시선 집중 영역 — 핵심 정보와 일치하는가
⑤ 거의 보지 않는 영역 — 스크롤 도달률과 교차 확인, 중요 정보가 여기 있으면 재배치 대상

Heatmap 데이터가 없으면 이 섹션은 세션 레코딩의 클릭 좌표·스크롤 행동으로 보완하고 "추정"임을 명시한다.

## 3. Session Recording 분석 (20개 목표)

네 그룹으로 나눠 공통 패턴을 비교한다:

- **전환 성공**: 어떤 경로로, 얼마 만에, 무엇을 확인하고 전환했는가
- **전환 실패**: 어디서 멈췄는가, 마지막 행동은 무엇인가
- **오래 머문 사용자**: 탐색인가 혼란인가 (반복 스크롤 여부로 구분)
- **빠른 이탈**: 첫 화면에서 무엇을 봤는가, 로딩·첫인상 문제인가

각 세션에서 찾을 행동 신호:

- 가장 오래 머무는 영역 / 반복 스크롤 / 위아래 왕복 스크롤 (정보 비교 중이거나 원하는 정보를 못 찾는 신호)
- 망설임(Hesitation): 커서가 요소 위에 오래 머묾 — 확신 부족
- 클릭 후 무행동: 피드백 부재 또는 로딩 문제
- 같은 버튼 반복 클릭: Rage Click 전조, 반응성 문제
- 선택 후 다시 변경: 선택 기준 불명확 (요금제 페이지 핵심 신호)
- 페이지 왕복: 비교 정보가 한 화면에 없음
- 갑작스러운 종료: 직전 행동·화면을 반드시 기록

## 4. Frustration 분석

각 지표의 발생 위치와 원인을 추정한다:

| 지표 | 대표 원인 |
|---|---|
| Rage Click | 반응 없는 UI, 느린 피드백, 비활성처럼 보이는 활성 버튼 |
| Dead Click | 클릭 가능해 보이는 비클릭 요소 (카드, 이미지, 밑줄 텍스트) |
| Quick Back | 기대 불일치 (링크 문구 vs 도착 페이지), 강제 가입 유도 |
| Excessive Scrolling | 정보 구조 문제, 찾는 정보 부재 |
| JS/Image Error | 기능·시각 요소 파손 — 발생 페이지와 브라우저 분포 확인 |

## 5. 성능 분석

LCP, INP, CLS, Slow Page 지표를 UX 영향으로 번역한다. 예: "LCP 4.2s → 첫 화면 지연으로 빠른 이탈 그룹의 N%가 콘텐츠 렌더 전 이탈(추정)". CLS가 높으면 오클릭 → Rage Click 연쇄를 의심한다.

## 6. Nielsen 10 휴리스틱 평가

각 항목마다 심각도(1~5), 문제 설명, 개선안을 작성한다. 심각도 기준: 1=사소한 불편, 3=전환에 영향, 5=전환 차단 수준.

1. 시스템 상태의 가시성 2. 시스템과 현실 세계의 일치 3. 사용자 제어와 자유 4. 일관성과 표준 5. 오류 예방 6. 기억보다 인식 7. 사용의 유연성과 효율성 8. 미학적이고 미니멀한 디자인 9. 오류 인식·진단·복구 지원 10. 도움말과 문서

## 7. UI 컴포넌트 평가 (요금제/가입 페이지인 경우)

요금제 카드, 선택 버튼, 가격 영역, 할인 정보, 배지, 필터, 정렬, Sticky 영역, 하단 CTA, 안내문 — 각각에 대해 평가와 개선안을 쓴다.

요금제 선택 영역은 추가로: 요금제 비교가 쉬운가, 가격이 이해되는가, 혜택이 눈에 들어오는가, 정보량이 과한가, 선택 기준이 명확한가, 사용자가 쉽게 결정할 수 있는가.

## 8. 모바일 UX (모바일 분석 시)

스크롤 길이, CTA 접근성(엄지 도달 영역), 손가락 이동 거리, 오조작 가능성, 선택하기 어려운 UI, 작은 터치 영역(44×44px 미만).

## 우선순위 산정

- **전환 방해 요소**: Critical(전환 차단) / High(상당수 이탈 유발) / Medium(마찰) / Low(개선 여지)
- **Backlog**: P0(즉시, 전환 직접 영향+저비용) / P1(다음 스프린트) / P2(백로그). 각 항목에 근거 데이터와 예상 효과(가능하면 수치, 아니면 "추정")를 붙인다.
