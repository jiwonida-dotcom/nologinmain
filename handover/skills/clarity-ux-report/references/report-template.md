# 리포트 템플릿 (단일 HTML)

## 문서 구조

아래 섹션 순서를 지킨다. 각 섹션은 앵커 내비게이션으로 연결한다.

1. **헤더**: 리포트 제목, 분석 대상 페이지/기간, 생성일, 데이터 소스 요약(세션 수 등)
2. **Executive Summary**: 3~5문장 + 핵심 KPI 카드 4~6개 (Sessions, Bounce, Dead Click 비율 등)
3. **전환 방해 요소 우선순위**: Critical/High/Medium/Low 배지가 붙은 목록
4. **문제 상세**: 문제별 카드 — 문제 / 원인 / 근거(Session Recording · Heatmap · Dashboard 각각 표기, 없으면 "추정" 배지) / 개선안 / 예상 효과
5. **Nielsen 휴리스틱 평가표**: 10행 테이블 (항목, 심각도 1~5, 문제, 개선안)
6. **UI 컴포넌트 평가**: 해당 시 테이블
7. **UX 개선 Backlog**: P0/P1/P2 그룹핑, 각 행에 작업·근거·예상 효과
8. **부록**: 데이터 한계, "추정" 항목 목록, 추가 수집 제안

## 스타일 가이드 (엄격히 준수)

Modern premium SaaS aesthetic. Apple 수준의 정밀함, Dribbble/Figma Community 품질.

- 밝은 흰색 인터페이스 + 부드러운 뉴트럴 배경 (`#FAFAFB` 계열)
- 주 강조색: 소프트 파스텔 퍼플 (예: `#8B7CF6`, 배경용 `#F1EEFE`)
- 큰 라운드 코너: 20–24px
- 얇고 미묘한 보더(`#ECECF1` 수준), 거의 보이지 않는 그림자
- 8px 스페이싱 시스템, 넉넉한 여백
- 볼드하고 현대적인 타이포그래피 (시스템 폰트 스택 + 한글은 Pretendard/Apple SD Gothic Neo 폴백)
- 시각적 노이즈 최소화, 불필요한 장식 없음
- 컴포넌트 스타일 전체 일관성

금지: glassmorphism, neumorphism, 무거운 그라데이션, 과한 그림자, skeuomorphic 효과, 과포화 색상.

## 시맨틱 컬러

배지·심각도에만 제한적으로 사용, 파스텔 톤 유지:

- Critical/P0: 파스텔 레드 (`#F87171` 텍스트, `#FEF1F1` 배경)
- High/P1: 파스텔 앰버 (`#F59E0B`, `#FEF7EC`)
- Medium: 파스텔 블루 (`#60A5FA`, `#EFF6FF`)
- Low/P2: 뉴트럴 그레이 (`#9CA3AF`, `#F4F4F6`)
- "추정" 배지: 퍼플 아웃라인 (강조색 계열)

## 구현 규칙

- CSS·JS 포함 **단일 HTML 파일**. 외부 의존성 없이 열리게 한다 (차트가 꼭 필요하면 cdnjs의 Chart.js만 허용, 실패해도 수치 테이블이 남도록 작성).
- 반응형: 1200px 컨테이너, 모바일에서 카드 1열.
- 심각도 1~5는 채워진 점 5개(●●●○○)로 시각화.
- KPI 카드: 큰 숫자 + 라벨 + 전기간 대비 변화(데이터 있으면).
- 인쇄 친화적일 것 (배경색 유지 여부와 무관하게 읽히는 대비).
