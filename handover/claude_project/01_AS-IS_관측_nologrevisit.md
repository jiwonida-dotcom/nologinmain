## 눈에 띄는 사실 (해석 아님, 확인 대상)
- 「가입신청서 작성」 직행 CTA는 본문에 없음 — 전체메뉴(햄버거) 안 「유심 신청서 작성 /onsale/joinIsMember?sbscTypCd2=U」로만 도달. 본문의 가입 경로는 요금제 목록 → 상세 → 신청 (간접)
- 자동 움직이는 요소 3종 동시: 이벤트 배너 자동 회전 · 요금제 세로 롤링 픽커 · 진입 팝업 슬라이드
- 데이터량 선택(5)은 페이지 전용 랜딩(`nologPpnSearchBann`) — 이 페이지에만 있는 가입 유도 장치
- 고객센터 3개 링크가 `javascript:void(0)` (JS 핸들러) — 동작 미확인
- 헤더 로그인 유도 문구 「로그인하시고, 유모바일 포인트도 모아보세요」(전체메뉴 내)
- 화면 캡처: 브라우저 패널 스크롤 캡처가 깨져 저장 못함 → 사용자 제공 또는 Chrome 확장 연결 후 재시도 필요
